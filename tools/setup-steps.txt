# Bundled phone setup. Existing screensaver choice is preserved. PC setup uses device.py.
1|Miqat is the home screen|ميقات هي الشاشة الرئيسية|am start -W -n tv.miqat.home/.MainActivity && cmd package set-home-activity --user 0 tv.miqat.home/.MainActivity
?|cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME | tail -n 1 | grep -q '^tv.miqat.home/'
# option:radio
0|Quran Radio level bars and sleep timer|مؤشّر صوت إذاعة القرآن ومؤقّت النوم|pm grant tv.miqat.home android.permission.RECORD_AUDIO && pm grant tv.miqat.home android.permission.WRITE_SECURE_SETTINGS
?|d=$(dumpsys package tv.miqat.home); echo "$d" | grep -q 'RECORD_AUDIO: granted=true' && echo "$d" | grep -q 'WRITE_SECURE_SETTINGS: granted=true'
1|Remote buttons and the call to prayer|أزرار جهاز التحكم والأذان|s=$(settings get secure enabled_accessibility_services); case "$s" in *tv.miqat.home/.RemoteKeys*|*tv.miqat.home/tv.miqat.home.RemoteKeys*) ;; ''|null) s=tv.miqat.home/.RemoteKeys ;; *) s="$s:tv.miqat.home/.RemoteKeys" ;; esac; settings put secure enabled_accessibility_services "$s" && settings put secure accessibility_enabled 1
?|settings get secure enabled_accessibility_services | grep -Eq 'tv[.]miqat[.]home/(tv[.]miqat[.]home)?[.]RemoteKeys' && [ "$(settings get secure accessibility_enabled)" = 1 ]
# option:startup
0|Starts by itself after a restart|يعمل وحده بعد إعادة التشغيل|appops set tv.miqat.home APP_AUTO_START allow 2>/dev/null; appops set tv.miqat.home APP_ASSOC_START allow 2>/dev/null; true
?|o=$(appops get tv.miqat.home APP_AUTO_START 2>&1); case "$o" in *allow*) true ;; *) false ;; esac
