What this proposal changes

HomeThe date opens the calendar. One city button refreshes location; without permission it opens the full Location page. Manual selection remains available through Settings.

Automatic locationOff by default. Enabling it explains background access before the Android permission flow. A denied permission leaves the toggle off and preserves the last location.

Hijri eventsSmall calendar markers, a selected-day event label, and one relevant Home line. No empty event row on ordinary days and no automatic event notifications.

Header choiceGreeting, the existing TV verse excerpt, or neither. One at a time, with no rotating text. The verse uses Miqat’s exact canonical sacred text.

Event examples use Arafah (9 Dhul-Hijjah), Eid al-Adha (10 Dhul-Hijjah), Ramadan, Eid al-Fitr and Ashura. Dates follow the app’s selected Hijri calendar and adjustment; local month announcements can differ. No fixed date is assigned to Laylat al-Qadr.

References: Qur’an 4:103 · Arafah & Ashura · Android background-location access. This prototype requests no real permissions.
